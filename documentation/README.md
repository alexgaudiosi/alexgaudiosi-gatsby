# Project Documentation

This folder stores durable project notes and local agent collaboration artifacts.

## Folders

- `agents/` - agent instructions, workflows, and project-specific notes.
- `sessions/` - local session logs and generated transcripts. Keep sensitive or temporary data here only; session artifacts are ignored by Git.

Prefer Markdown for durable documentation. Include the date and a short topic in filenames, for example `agents/2026-09-21-dependency-upgrades.md`.
